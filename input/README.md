# Your source photos

This folder is git-ignored. Put the bride's photos here:

  face-front.jpg   head + shoulders, face fills ~half the frame, eyes open,
                   hair clear of the eye area, shoulders visible
  face-right.jpg   same session, head turned ~45 degrees right
  face-left.jpg    same session, head turned ~45 degrees left
  full-body.jpg    whole body, standing, facing camera, plain background
  hands.jpg        optional, only for ring / bracelet / nail try-on

Shoot at 1500px or more on the long side. The app downscales to the API's
1024px limit but never upscales, and the makeup endpoints reject small faces.

Full spec, including every error code these guard against: docs/ASSETS.md
